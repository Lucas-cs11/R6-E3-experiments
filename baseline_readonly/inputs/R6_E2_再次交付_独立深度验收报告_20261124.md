## 6. 新执行反例：R6-10 观测单射性（P0）

源码：`implementations/subject/r610.py`；当前核心：

```python
observations = [pair['observation_map'][k] for k in sorted(logical)]
checks['observation_injective'] = len(observations) == len(set(observations))
```

这一代码把不同执行路径 ID 映射到不同 `Y` 的要求，当成第五章从**不同任务完成观测 `omega_c`** 到不同 `Y` 的单射要求。两条不同路径完全可能有同一 `omega_c`，因而允许同一 `Y`。我在输入级构造两条重复观测的正常路径及一条具有不同观测的故障路径，全部其他显式检查为真，主体及参考均输出 `THEOREM_NOT_APPLICABLE` 且唯一失败键为 `observation_injective`。当前接口甚至没有显式存储每条路径的 `omega_c`，无法完成正确单射证明。应按任务完成观测的等价类验证，并在原始 PN 轨迹上重建 `omega_c`。

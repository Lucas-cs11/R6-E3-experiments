# 论文实验部分成果记录本

> 用途：记录已经由独立复算或模型驱动验证的事实，并用论文自身的概念表述。每条按统一单元书写：**事实**（发生了什么）— **产出/结果**（得到什么可写入正文的内容）— **影响**（对正文表述、方法、引理或后续实验步骤的作用）。证据等级：`独立复算` / `模型验证` / `经验测量`。未决事项只进第八节。

## 一、时间语义与判定语义的健全性

### 1.1 强时间语义的自洽性

- **事实**：持续使能语义下"被中间标识打断的时钟重新初始化"这一规则，在两种彼此独立的时间表示（相对时钟龄与绝对时刻）中得到完全一致的可诊断性结论。
- **产出/结果**：该时间语义在实现层面无歧义；任何判定不依赖时间表示的选择。
- **影响**：正文关于强时间语义的设定可直接作为方法前提；实现章节可声明"时间表示无关性"这一性质，后续实验无需对时间表示做敏感性分析。

### 1.2 三值判定与证据完整性

- **事实**：凡判定为"可诊断"的故障—首次完成对均附穷尽枚举证据，凡判定为"不可诊断"的均附实际反例运行对；未出现无证据的肯定判定或无实例的否定判定。
- **产出/结果**：判定三值（可诊断、不可诊断、未决）与证据类型（完备证书、反例轨迹、资源耗尽记录）一一对应。
- **影响**：支撑正文"判定必须附证据"的方法论声明；为后续所有全量统计规定口径——可诊断率的分母只含真正完成穷尽者，未决不被算作否定。

### 1.3 未决随规模的单调性

- **事实**：在预先声明的资源上限内无法完成穷尽枚举的实例记为未决；未决比例随机器数、工序数、在制品上界与故障位置数单调上升。
- **产出/结果**：可诊断性存在明确的规模边界，且边界位置可由参数刻画。
- **影响**：为正文"有界分析"的定位提供实证；决定后续全量实验必须按参数轴分层报告，而非只报总率。

## 二、故障位置与有界完成域的结构事实

### 2.1 故障位置的饱和语义

- **事实**：生成规则中"故障位置数"是请求上限；当请求值超过实际使用的机器数时，实际故障机器数与故障变迁数饱和，无一例外。
- **产出/结果**：该参数的正确语义是"请求上限并受机器数饱和"，而非"精确的故障位置数"。
- **影响**：正文若按"精确数量"表述需修正（已提交理论侧）；后续统计必须区分请求值与实际值，饱和配置单列分层，不得与常规配置混算。

### 2.2 名义配置、规范内容与运行规格的三量分离

- **事实**：形式合法的名义配置数、规范网络内容数、运行规格数三者互不相同；同一规范网络内容可由多个名义配置产生。

| 量 | 数值 |
|---|---:|
| 候选配置总数 | 143,360 |
| 形式合法（满足冻结的静态规则） | 107,520 |
| 形式非法（保留并注明失效规则） | 35,840 |
| 其中故障位置饱和的配置 | 3,840 |
| 规范网络内容（去重后） | 85,024 |
| 主域运行规格数（合法配置 × 四种组织方式） | 430,080 |

- **产出/结果**：任何统计都存在"以名义配置为单位"与"以内容为单位"两种口径；内容口径为名义口径的约 79.1%（85,024/107,520 合法配置），重复配置不构成独立证据。
- **影响**：正文实验设计须同时报告两种口径并说明非独立性；后续所有比例与速率的分母必须显式标注口径，禁止混用。

## 三、概率层：Bayes 误差与可靠覆盖

### 3.1 基准模型的精确可复算性

- **事实**：连续时间基准模型（正常完成由两个并行计时器最大值给出、故障完成服从一维区间均匀分布）的 Bayes 误差与可靠覆盖，可由模型结构逐点精确复算；全部二十一个参数点上与论文闭式表达式有理数严格相等。
- **产出/结果**：基准模型的概率量不依赖数值近似即可验证；公式与模型结构一致。
- **产出/结果（数值）**：二十一个参数点（左端 3，步长 1/20，至右端 4）的误差与覆盖逐点相等，节选如下（全部为有理数精确值）：

| 参数 a4 | Bayes 误差 Pe | 可靠覆盖 Γ |
|---|---|---|
| 3（左端） | 1/4 = 0.2500 | 1/2 = 0.5000 |
| 13/4 | 3/16 = 0.1875 | 67/112 ≈ 0.5982 |
| 7/2（中点） | 1/8 = 0.1250 | 17/24 ≈ 0.7083 |
| 15/4 | 1/16 = 0.0625 | 67/80 = 0.8375 |
| 4（右端） | 0 | 1 |

- **影响**：支撑正文概率层公式的正确性声明；该基准可作为后续全量概率实验的校准参照（每族分布族都须先通过同类精确性检验）。

### 3.2 端点值校核

- **事实**：参数取左端时误差为 1/4、覆盖为 1/2；中点时 1/8 与 17/24；右端时 0 与 1。
- **产出/结果**：与正文陈述逐值吻合。
- **影响**：可作为正文算例的权威数值来源；后续图表以这些值为锚点。

### 3.3 逻辑层与概率层时间参数的独立性

- **事实**：有界完成域的时间参数与概率层的时间参数相互独立，按正文要求不逐项相等。
- **产出/结果**：两层实验可分别设定时间参数而不破坏理论一致性。
- **影响**：后续概率实验无需与逻辑域时间参数对齐，减少一个伪约束。

### 3.4 可靠覆盖的定义域问题（待裁定）

- **事实**：闭式覆盖对应的可靠区域以**计划正常时长**落在故障窗口之前划分；若改以**观测到的完成时刻**划分，中点处覆盖由 17/24 变为 7/8。
- **产出/结果**：存在两种物理语义的可靠覆盖，数值不同：

| 参数 a4 | 按计划正常时长（=论文闭式） | 按观测完成时刻 | 差值 |
|---|---|---|---|
| 3 | 1/2 = 0.5000 | 1/2 = 0.5000 | 0 |
| 7/2 | 17/24 ≈ 0.7083 | 7/8 = 0.8750 | +0.1667 |
| 4 | 1 | 1 | 0 |

- **影响**：正文该量的定义需明确；在裁定前，任何覆盖数值须同时报告两种定义，后续概率实验的覆盖结果按裁定口径归档。

### 3.5 即时子类的精确质量传播

- **事实**：在即时变迁受限子类上，故障与正常质量沿网络结构的传播可做到有理数意义下精确，且与密度积分的独立推导一致。
- **产出/结果**：概率层的"传播"步骤在受限子类无近似误差。
- **影响**：为正文概率算法的精确性提供支撑；后续全量概率实验可对即时子类直接采信传播值作参照。

## 四、观测量化与信息损失

### 4.1 量化破坏观测单射

- **事实**：将连续观测按半单位或单位栅格粗化后，不同运行对可被映射到同一观测类别，单射条件一般不成立。
- **产出/结果**：以恒等观测为前提的充分定理不能直接用于量化观测场景。
- **影响**：正文需明确量化观测属于另一分析分支；后续概率实验中对量化规则须单独标注"不援引跨层充分条件"。

### 4.2 量化代价的经验测量

- **事实**：真实工业数据上，把连续量测特征二值化后，判别力（曲线下面积）由 0.8588 降至 0.7935，下降约 6.5 个百分点（精确差值 0.0653）。
- **产出/结果**：观测精度与可诊断上限之间存在可测量的联系。
- **影响**：为正文"观测精度决定诊断上限"的论断提供实证注脚；提示后续实验应把观测粗化作为独立敏感性维度。

## 五、工业数据的经验评价

### 5.1 同题经验比较

- **事实**：在共同可比工件集上（可评价工件 1,421 件，其中正例 680、负例 741），四种判别方式的指标如下：

| 方法 | 曲线下面积 | Brier 分数 | 对数损失 | 平衡准确率 |
|---|---:|---:|---:|---:|
| 论文方法 | 0.8488 | 0.1574 | 0.4745 | 0.7526 |
| 梯度提升树 | 0.8588 | 0.1499 | 0.4562 | 0.7738 |
| 随机森林 | 0.8521 | 0.1555 | 0.4760 | 0.7742 |
| 逻辑回归 | 0.7748 | 0.1899 | 0.5578 | 0.6970 |

- **产出/结果**：论文方法与主流学习器处于同一量级（与最强基线差 0.0100），未显著劣于最强基线，明显优于线性模型（差 0.0740）。
- **影响**：正文经验评价章节可作"方法具竞争力"的表述，但不作"最优"声明；后续不得以经验结果替代严格逻辑认证。

### 5.2 统计稳定性与不可认证边界

- **事实**：自助法重采样（工件级，200 次）下四项指标的 95% 区间为：曲线下面积 [0.8401, 0.8786]、Brier [0.1391, 0.1604]、对数损失 [0.4317, 0.4835]、平衡准确率 [0.7502, 0.7945]；原始记录共 5,000 条（合格 4,307、不合格 693），可评价共同子集 1,421 条，其余 3,579 条保留并注明排除原因。工业数据的完成信号为外部观测，物理缺陷到故障变迁实际发射缺少可核查映射。
- **产出/结果**：判别力统计稳定；但这些工件只能作经验比较，不能升级为严格概率证书。
- **影响**：正文须声明经验评价与严格认证的分界；后续任何"严格风险"结论不得引用该子集。

### 5.3 不合格工件的保留原则

- **事实**：不合格工件全部保留并逐条注明不可评价原因；可评价工件构成明确共同子集，不同分母结果不被直接排名。
- **产出/结果**：经验评价有完整清单覆盖与排除理由。
- **影响**：为正文数据使用规范提供范例；后续所有对比实验沿用"共同子集 + 完整清单"的报告方式。

## 六、历史证据的可复现性

### 6.1 无时间投影查询的印证与修正

- **事实**：旧有无时间投影完成查询共 107,520 行，其中账本原记为有界 104,052 行、超时 3,468 行；逐行核对原始输出后，107,520 行中有 104,212 行的有界性结论获直接印证，3,308 行保持有界性未决；其中 160 行原记为超时、但其原始输出中已含"有界"查询结论，属"查询完成、后续阶段超时"，改记为有界性已证明并保留存活性未决。
- **产出/结果**：得到修正后的有界性与未决两本账。
- **影响**：正文历史数据可用性说明应据此修正；后续引用历史投影结果时必须使用修正口径。

### 6.2 三十二工况的部分可复现

- **事实**：三十二个工况中，三十一个的数值（误差区间、覆盖区间、阈值判定）可逐项复现，但原推理引擎字节、路径与积分日志不可获得，部分记录带时间或分裂预算截断；旧"通过"结论（3 个）未获重新认证，其中一个工况因数据不足保持不可重认证。分类计数：完全重新认证 0、部分可复现 31、不可重认证 1。
- **产出/结果**：历史工况结论的可信等级被明确降级。
- **影响**：正文不得将旧工况结果作为已验证结论引用；后续实验不得以旧"通过"数量作为完成度依据。

### 6.3 撤回结论的归档

- **事实**：旧报告中"全体无界""概率测算完成""风险公式"等结论与当前可复算事实不符。
- **产出/结果**：相关表述撤回并标注不可引用，原始材料保留。
- **影响**：正文相关段落须以当前复算结果替换；后续写作以此为唯一口径。

## 七、方法的工程可行性

### 7.1 单实例判定成本可稳定估计

- **事实**：在预先声明的资源上限下，单实例判定耗时中位 0.80 秒、第 95 百分位 4.40 秒、最大 10.4 秒（修复前最大可达近 600 秒，系资源核算缺项所致，已修复并锁定回归测试）；耗时随规模平滑增长。
- **产出/结果**：方法具备可执行性，成本可外推。
- **影响**：支撑正文"工程可行"的声明；为后续全量实验的规模设定与预算声明提供依据。

### 7.2 组织方式不影响结论

- **事实**：配对同步（只比较观测与完成状态一致的运行对）与包络分组（按统计特征分组而不剪枝）不改变判定结论，只改变计算量；四种组织方式在同一批实例上结论一致。
- **产出/结果**：算法的等价变体在结论层面可互换。
- **影响**：正文可声明这些变体为纯效率手段；后续性能比较不得把这些变体当作不同方法排名。

# 论文实验部分成果记录本

> 用途：记录已经由独立复算或模型驱动验证的事实，用论文自身的概念表述。每条按统一单元书写：**事实**（结论本身）— **实验开展过程**（该结论由怎样的实验、以什么数据、按什么机制得到）— **产出/结果**（可写进正文的内容与数值）— **影响**（对正文表述、方法、引理或后续实验步骤的作用）。证据等级：`独立复算` / `模型验证` / `经验测量`。未决事项只进第八节。


## 〇、术语与机制释义

首次阅读本记录前，先明确以下概念（均按论文正文的用法）：

| 术语 | 含义 |
|---|---|
| 定时Petri网（含连续时间） | 在普通Petri网的标识之上，为每个计时变迁附带一个时间区间：该变迁在使能后需经历区间内某一时长才能发生；模型中另可含不耗时的即时变迁。 |
| 强时间语义 | 持续使能的变迁在被中间标识打断后，其已累积的时间清零，重新使能时从头计时；只有持续使能期间的时间才计入。 |
| 即时变迁优先 | 当即时变迁与计时变迁同时使能时，先让即时变迁发生，至再无即时变迁可使能为止。 |
| 故障变迁 / 首次完成 | 故障变迁是模型中代表物理缺陷实际发生的变迁；首次完成是运行第一次进入完成标识集合的时刻。二者共同定义一个"故障—首次完成对"。 |
| 有界完成域 | 对故障发生后的时间设一个上限，只考察该上限之内的运行；超出上限才完成的运行不计入分析。 |
| 可观测量 | 一次运行从外部能看到的全部信息：可见的标识序列（或称可见词）与首次完成的总时长。内部隐藏的变迁序列不可见。 |
| 可诊断 / 不可诊断 / 未决 | 可诊断：正常假设与故障假设下产生的全部可观测量互不重叠，且枚举已穷尽（附完备证据）；不可诊断：存在两条运行，其可观测量完全相同但分属两假设（附反例）；未决：在声明的资源上限内未能枚举穷尽，不下结论。 |
| 资源上限（节点预算 / 约束预算） | 枚举时预先声明的两道闸：其一限制可访问的标识数，其二限制同时保存的约束量；任一闸到达即停止并记未决。二者都必须在实验开始前声明，不得事后调整。 |
| 名义配置 / 规范网络内容 / 运行规格 | 名义配置：由八个结构参数唯一确定的一个候选；规范网络内容：把与参数无关的结构部分规范化后得到的指纹，多个名义配置可对应同一内容；运行规格：一个名义配置配一种组织方式的组合。 |
| 饱和 | 生成规则中"故障位置数"是请求上限：请求值超过机器数时实际故障机器数只能取到机器数，超过部分被"饱和"掉。 |
| 组织方式 | 在同一判定语义下的四种计算组织：完全枚举；保留全部历史；按同步约束只比较观测与完成状态一致的运行对；按包络统计特征分组而不剪枝。四者结论应当相同，差异只在计算量。 |
| Bayes 误差 | 两假设先验各半时，任何判别规则的最小平均错误率，等于两假设下观测分布的逐点较小值在重叠区间上的积分。 |
| 可靠覆盖 | 判别规则给出确定的（非弃权）结论时，该结论正确的概率意义上的覆盖比例；可靠区域如何划分会出现两种定义（见 3.4）。 |
| 观测单射 | 不同运行对是否总能得到不同的观测；若两个不同运行对的观测完全相同，则单射不成立。 |
| 观测类别 / 栅格量化 | 把连续观测按固定单位取整后，原观测被归入有限的类别（单位栅格或半单位栅格）。 |
| 工件级划分 | 工业数据的训练集、校准集与留出集按物理工件划分，同一工件的左右两侧必须留在同一集合，避免同一工件的数据跨越评价边界造成泄漏。 |
| 共同可评价子集 | 多种方法在相同工件上都能给出结果的那些工件；不同方法的不可评价记录不进入共同子集，也不允许删除。 |
| 自助法重采样 | 以工件为单位有放回地重复抽样，每次用重采样集合重算指标，由此得到指标的不确定性区间。 |
| 分层取样 | 按若干结构参数（机器数、零件类型数、工序数、在制品上界、故障位置数等）把总域划成若干层，在每层内取样或全部取用，使样本在每一参数取值上都有代表；若八参数组合在域内唯一，则退化为按参数边际覆盖的均匀取样。 |
| 精确积分（有理数） | 按密度分段点把积分区间切分，每段用解析原函数求值，全程以分数运算，不引入浮点舍入。 |
| 证据等级 | 独立复算：从原始证据由本工作区重新计算；模型验证：由冻结数学模型的真实结构推导验证；经验测量：真实工业数据上的统计结果。 |

## 一、时间语义与判定语义的健全性

### 1.1 强时间语义的自洽性

- **事实**：持续使能语义下"被中间标识打断的时钟重新初始化"这一规则，在两种彼此独立的时间表示（相对时钟龄与绝对时刻）中得到完全一致的可诊断性结论。
- **实验开展过程**：取同一组定时Petri网模型，对每个模型分别用两种时间表示各实现一遍判定机制：一种把每个使能变迁的年龄记为自其上一次被使能以来经过的相对时间，另一种把每个使能变迁的年龄记为绝对时刻之差并在中间标识处显式重设。对每个模型、每种组织方式，两套实现各自枚举全部合法运行、计算首次完成时刻、比较故障假设与正常假设下的可观测量，最后对三项判定（可诊断、不可诊断、未决）逐一比对。两组实现的结论若有一处不同即判为不一致。
- **产出/结果**：全部被比较的模型与组织方式上，两套时间表示的判定结论完全一致，无一处分歧。
- **影响**：正文关于强时间语义的设定可直接作为方法前提；实现章节可声明"时间表示无关性"；后续实验无需对时间表示做敏感性分析。

### 1.2 三值判定与证据完整性

- **事实**：凡判定为"可诊断"的故障—首次完成对均附穷尽枚举证据，凡判定为"不可诊断"的均附实际反例运行对；未出现无证据的肯定判定或无实例的否定判定。
- **实验开展过程**：对每个被检验的定时Petri网，先按冻结的静态规则确认其形式合法性，再在声明的时间界内枚举故障发生后至首次完成的全部合法运行。枚举采用广度优先的标识推进：每到达一个新标识即按强时间语义计算所有使能变迁的可发生时间区间，即时变迁优先，非即时变迁的年龄在被打断时清零。对每个到达完成标识的运行，记录其外部可见词与首次完成总时长，构成可观测量。随后按观测值分组，检查"同一观测值是否对应两条分别属于故障假设与正常假设的运行"：若存在即成反例（不可诊断），若全部观测值互斥归类且枚举已穷尽则成证书（可诊断）。若枚举在预算内未完成，则该实例记未决并保留已枚举部分。
- **产出/结果**：判定三值（可诊断、不可诊断、未决）与证据类型（完备证书、反例轨迹、资源耗尽记录）一一对应；在被检验实例中，无一处出现"肯定判定缺证据"或"否定判定缺反例"。
- **影响**：支撑正文"判定必须附证据"的方法论声明；为后续全量统计规定口径——可诊断率的分母只含真正完成穷尽者，未决不算作否定。

### 1.3 未决随规模的单调性

- **事实**：在预先声明的资源上限内无法完成穷尽枚举的实例记为未决；未决比例随机器数、工序数、在制品上界与故障位置数单调上升。
- **实验开展过程**：在冻结的候选配置总域上取样，方式如下：
  1. **分层依据**：八个结构参数分别为机器数、零件类型数、每件工序数、在制品上界、不可观测事件占比、故障位置请求数、时间区间宽度因子、可调节动作占比；它们共同决定模型规模与结构。
  2. **取样方式**：先对总域内每一层（八参数组合）检查其在域内是否唯一——本域内八参数组合互不相同，因此在层内只能取一个样本；为保证每一参数的每个取值都有足够代表，改用参数边际覆盖的均匀取样：对总域做确定性随机置换，取前 N 个样本，并逐参数统计各取值在样本中的出现次数，作为覆盖表一并记录。
  3. **样本规模**：探针阶段取 2,000 个配置，每个配置配四种组织方式，共 8,000 次判定；正式全域不做取样，直接覆盖全部 107,520 个形式合法配置（430,080 次判定）。
  4. **执行与统计**：对每个样本在声明的资源上限（节点预算与约束预算）下执行与 1.2 相同的枚举过程，记录结局（可诊断、不可诊断、未决）与各参数取值；再按参数轴分组统计未决比例并检验单调趋势。所有结局以原始记录为准，不剔除任何结局。
- **覆盖表示例**（探针阶段 2,000 样本的边际覆盖，节选）：故障位置请求数 1 出现 655 次、2 出现 647 次、4 出现 515 次、8 出现 183 次；可调节动作占比 0.1 出现 484 次、0.25 出现 454 次、0.5 出现 536 次、0.75 出现 526 次。
- **产出/结果**：可诊断性存在明确的规模边界；未决比例沿四个规模参数单调上升，边界位置可由参数取值刻画。
- **影响**：为正文"有界分析"的定位提供实证；决定后续全量实验必须按参数轴分层报告，而非只报总率。

## 二、故障位置与有界完成域的结构事实

### 2.1 故障位置的饱和语义

- **事实**：生成规则中"故障位置数"是请求上限；当请求值超过实际使用的机器数时，实际故障机器数与故障变迁数饱和，无一例外。
- **实验开展过程**：从候选配置总域中取出所有请求故障位置数高于其机器数取值的配置（共 3,840 个），逐个生成对应模型，记录三项量：请求的故障位置数、模型实际使用的机器数、模型中实际出现的故障变迁数。随后对每个配置比较请求值与实际值，并检验实际故障机器数是否恰等于机器数。全部配置逐一核验，不做抽样。
- **产出/结果**：3,840 个配置全部呈饱和：请求值高于实际值，实际故障机器数等于机器数。

| 量 | 数值 |
|---|---:|
| 请求值高于机器数的配置 | 3,840 |
| 其中实际发生饱和的配置 | 3,840（100%） |

- **影响**：正文若按"精确数量"表述该参数需修正（已提交理论侧）；后续统计必须区分请求值与实际值，饱和配置单列分层，不得与常规配置混算。

### 2.2 名义配置、规范内容与运行规格的三量分离

- **事实**：形式合法的名义配置数、规范网络内容数、运行规格数三者互不相同；同一规范网络内容可由多个名义配置产生。
- **实验开展过程**：对候选配置总域逐一做形式合法性判定（按冻结的静态规则逐条检查），得到形式合法与形式非法两类；对每个形式合法配置生成模型后，将模型的结构内容（标识、变迁、弧、时间区间等与参数无关的部分）规范化并计算内容指纹，按指纹去重得到规范网络内容数；再对每个合法配置配以四种组织方式，得到运行规格数。三个量分别计数并交叉核对，重复内容的成因逐条列出（参数不改变结构的情形）。
- **产出/结果**：

| 量 | 数值 |
|---|---:|
| 候选配置总数 | 143,360 |
| 形式合法（满足冻结的静态规则） | 107,520 |
| 形式非法（保留并注明失效规则） | 35,840 |
| 其中故障位置饱和的配置 | 3,840 |
| 规范网络内容（去重后） | 85,024 |
| 主域运行规格数（合法配置 × 四种组织方式） | 430,080 |

内容口径为名义口径的约 79.1%（85,024/107,520），重复配置不构成独立证据。
- **影响**：正文实验设计须同时报告两种口径并说明非独立性；后续所有比例与速率的分母必须显式标注口径，禁止混用。

## 三、概率层：Bayes 误差与可靠覆盖

### 3.1 基准模型的精确可复算性

- **事实**：连续时间基准模型（正常完成由两个并行计时器的最大值给出、故障完成服从一维区间上的均匀分布）的 Bayes 误差与可靠覆盖，可由模型结构逐点精确复算；全部二十一个参数点上与论文闭式表达式有理数严格相等。
- **实验开展过程**：按论文给出的真实结构建模——两个相互独立的并行计时器分别服从各自区间上的均匀分布，正常完成时间取二者最大值，故障完成时间服从以参数为左端点的均匀分布，两假设先验各半。对每个参数取值，先由并行计时器的分布导出正常完成的概率密度（取最大值分布的分段多项式形式，2 至 3 区间为线性、3 至 4 区间为常数），再与故障密度在共同支撑上比较：Bayes 误差由两密度的逐点较小值在重叠区间上的积分给出，可靠覆盖由可靠区域内两分布的相应质量给出。积分按密度分段点精确切分，每段以有理数解析积分，不采用数值近似；同一结果另以细分的数值积分独立核对。最后与论文闭式表达式逐点作有理数相等比较。
- **产出/结果**：二十一个参数点（左端 3，步长 1/20，至右端 4）的误差与覆盖逐点相等，节选如下（全部为有理数精确值）：

| 参数 a4 | Bayes 误差 Pe | 可靠覆盖 Γ |
|---|---|---|
| 3（左端） | 1/4 = 0.2500 | 1/2 = 0.5000 |
| 13/4 | 3/16 = 0.1875 | 67/112 ≈ 0.5982 |
| 7/2（中点） | 1/8 = 0.1250 | 17/24 ≈ 0.7083 |
| 15/4 | 1/16 = 0.0625 | 67/80 = 0.8375 |
| 4（右端） | 0 | 1 |

- **影响**：支撑正文概率层公式的正确性声明；该基准可作为后续全量概率实验的校准参照（每个分布族都须先通过同类精确性检验）。

### 3.2 端点值校核

- **事实**：参数取左端时误差为 1/4、覆盖为 1/2；中点时 1/8 与 17/24；右端时 0 与 1。
- **实验开展过程**：从 3.1 的二十一点复算中取出左端、中点、右端三个取值，与正文陈述的对应数值逐项对照；三处均要求有理数严格相等，任一处不等即判为不一致。
- **产出/结果**：三处端点值与正文陈述逐值吻合。
- **影响**：可作为正文算例的权威数值来源；后续图表以这些值为锚点。

### 3.3 逻辑层与概率层时间参数的独立性

- **事实**：有界完成域的时间参数与概率层的时间参数相互独立，按正文要求不逐项相等。
- **实验开展过程**：在概率层实验的每次配置中，刻意使概率模型的时间参数与逻辑层有界完成域的时间参数取不同值，并验证两层的判定结论各自不受对方参数影响：逻辑层只关心运行对是否可区分，概率层只关心观测分布。两组参数分别记录，不互相代入。
- **产出/结果**：两层实验可分别设定时间参数而不破坏理论一致性。
- **影响**：后续概率实验无需与逻辑域时间参数对齐，减少一个伪约束。

### 3.4 可靠覆盖的定义域问题（待裁定）

- **事实**：闭式覆盖对应的可靠区域以**计划正常时长**落在故障窗口之前划分；若改以**观测到的完成时刻**划分，中点处覆盖由 17/24 变为 7/8。
- **实验开展过程**：对同一参数取值，分别按两种定义计算可靠覆盖：其一以计划正常时长的分布（单一时钟器的均匀分布）在故障窗口之前的质量计；其二以实际观测到的完成时刻（两个计时器最大值）的分布在故障窗口之前的质量计。两种计算都使用同一批模型结构与同一精确积分方法，只改变可靠区域的划分依据。
- **产出/结果**：

| 参数 a4 | 按计划正常时长（=论文闭式） | 按观测完成时刻 | 差值 |
|---|---|---|---|
| 3 | 1/2 = 0.5000 | 1/2 = 0.5000 | 0 |
| 7/2 | 17/24 ≈ 0.7083 | 7/8 = 0.8750 | +0.1667 |
| 4 | 1 | 1 | 0 |

- **影响**：正文该量的定义需明确；在裁定前，任何覆盖数值须同时报告两种定义，后续概率实验的覆盖结果按裁定口径归档。

### 3.5 即时子类的精确质量传播

- **事实**：在即时变迁受限子类上，故障与正常质量沿网络结构的传播可做到有理数意义下精确，且与密度积分的独立推导一致。
- **实验开展过程**：构造只含即时变迁与有限个计时变迁的受限子类模型，先按结构把初始标识处的先验质量分配到各即时变迁上，再沿使能与发射关系逐步把质量推移到完成标识；每一步的质量均以有理数运算，不做舍入。同一批模型另以密度积分的方式（对完成时刻的分布直接积分）独立计算各终态质量，两种方法逐模型比较。
- **产出/结果**：受限子类上传播结果与积分推导逐模型一致，无一处舍入误差。
- **影响**：为正文概率算法的精确性提供支撑；后续全量概率实验可对即时子类直接采信传播值作参照。

## 四、观测量化与信息损失

### 4.1 量化破坏观测单射

- **事实**：将连续观测按半单位或单位栅格粗化后，不同运行对可被映射到同一观测类别，单射条件一般不成立。
- **实验开展过程**：对同一批模型，分别使用三种观测映射：恒等映射（保留完成时刻原值）、半单位栅格（把完成时刻向下取整到半个单位）、单位栅格（向下取整到整单位）。对每种映射，按 1.2 的枚举过程收集全部运行的观测类别，检查"不同运行对是否落入同一类别"；恒等映射下若单射成立，再检验两种栅格映射下是否出现类别合并，并给出具体的合并实例。
- **产出/结果**：两种栅格映射下均出现类别合并（单射不成立），并给出实例；恒等映射下未出现合并。
- **影响**：正文需明确量化观测属于另一分析分支；后续概率实验中对量化规则须单独标注"不援引跨层充分条件"。

### 4.2 量化代价的经验测量

- **事实**：真实工业数据上，把连续量测特征二值化后，判别力（曲线下面积）由 0.8588 降至 0.7935，下降约 6.5 个百分点（精确差值 0.0653）。
- **实验开展过程**：在真实的螺钉拧紧工艺数据上，取可评价工件构成共同集合（同一工件左右两侧不跨集合，按工件级划分）。先以完整连续特征训练判别模型并在留出工件上评价；再把连续特征按中位数二值化（每维只保留"高/低"两档），以相同划分、相同随机种子重新训练同一模型并在同一留出集合上评价。两次评价使用完全相同的工件集合与标签，只改变观测的精细程度。
- **产出/结果**：二值化后曲线下面积下降 0.0653；该差值在留出集合上稳定复现。
- **影响**：为正文"观测精度决定诊断上限"的论断提供实证注脚；提示后续实验应把观测粗化作为独立敏感性维度。

## 五、工业数据的经验评价

### 5.1 同题经验比较

- **事实**：在共同可比工件集上（可评价工件 1,421 件，其中正例 680、负例 741），论文方法与三种学习器的指标如下：

| 方法 | 曲线下面积 | Brier 分数 | 对数损失 | 平衡准确率 |
|---|---:|---:|---:|---:|
| 论文方法 | 0.8488 | 0.1574 | 0.4745 | 0.7526 |
| 梯度提升树 | 0.8588 | 0.1499 | 0.4562 | 0.7738 |
| 随机森林 | 0.8521 | 0.1555 | 0.4760 | 0.7742 |
| 逻辑回归 | 0.7748 | 0.1899 | 0.5578 | 0.6970 |

- **实验开展过程**：从真实数据的全部记录（5,000 条）中按冻结的工件级划分取出可评价集合：训练与校准使用一部分工件，留出使用另一部分；同一工件的左右两侧始终留在同一集合。对论文方法，使用其冻结的判别输出；对三种学习器，使用相同的特征、相同的划分与固定随机种子重新训练并在同一留出集合上评价。四种方法只在"共同可评价工件"上计算指标（1,421 件），不同方法的不可评价记录不参与其分母，也不互相替代。指标包括曲线下面积、Brier 分数、对数损失与平衡准确率，均按类别、左右侧与完成状态分层报告。
- **产出/结果**：论文方法与最强基线差 0.0100、与线性模型差 0.0740，处于同一量级。
- **影响**：正文经验评价章节可作"方法具竞争力"的表述，但不作"最优"声明；后续不得以经验结果替代严格逻辑认证。

### 5.2 统计稳定性与不可认证边界

- **事实**：工件级自助法重采样（200 次）下四项指标的 95% 区间为：曲线下面积 [0.8401, 0.8786]、Brier [0.1391, 0.1604]、对数损失 [0.4317, 0.4835]、平衡准确率 [0.7502, 0.7945]；原始记录共 5,000 条（合格 4,307、不合格 693），可评价共同子集 1,421 条，其余 3,579 条保留并注明排除原因。
- **实验开展过程**：在共同可评价工件集合上按工件为单位做有放回重采样，每次重采样后重算四项指标，共 200 次，取 2.5% 与 97.5% 分位作为区间。同时逐条登记被排除记录的原因（未完成、类别不可判、配对缺失等），不删除任何记录。工业数据的完成信号是外部观测，物理缺陷与故障变迁实际发射之间没有可核查的映射，因此这些结果只作为经验统计，不进入严格概率证书。
- **产出/结果**：判别力统计稳定；严格认证边界明确。
- **影响**：正文须声明经验评价与严格认证的分界；后续任何"严格风险"结论不得引用该子集。

### 5.3 不合格工件的保留原则

- **事实**：不合格工件全部保留并逐条注明不可评价原因；可评价工件构成明确共同子集，不同分母结果不被直接排名。
- **实验开展过程**：在构建工件清单时，对每条原始记录同时登记其物理来源、左右侧、类别、数据完整性状态与完成状态；凡不可评价者，写明具体原因（例如未完成、序列缺步、无对应完成信号），而不是从总体清单中删除。评价时先确定共同可评价子集，再在该子集上比较各方法。
- **产出/结果**：经验评价有完整清单覆盖与排除理由；分母一致。
- **影响**：为正文数据使用规范提供范例；后续所有对比实验沿用"共同子集 + 完整清单"的报告方式。

## 六、历史证据的可复现性

### 6.1 无时间投影查询的印证与修正

- **事实**：旧有无时间投影完成查询共 107,520 行，其中账本原记为有界 104,052 行、超时 3,468 行；逐行核对原始输出后，104,212 行的有界性结论获直接印证，3,308 行保持有界性未决；其中 160 行原记为超时、但其原始输出中已含"有界"查询结论，属"查询完成、后续阶段超时"，改记为有界性已证明并保留存活性未决。
- **实验开展过程**：对旧有外部工具在无时间投影上的每一行查询结果，取回其原始标准输出与退出状态，按查询层面解析：先确认该行查询的是哪个模型的什么性质，再看标准输出中是否出现该查询的最终结论；若结论出现而后续存活性分析阶段超时，则该行的有界性记为已证明、存活性记为未决。解析结果由独立程序从头重放一遍，逐行核对计数，任何无法绑定原始输出的行都保持原状并单独列出。
- **产出/结果**：修正后的两本账与逐行绑定记录；160 行的改记有原始输出为证。
- **影响**：正文历史数据可用性说明应据此修正；后续引用历史投影结果时必须使用修正口径。

### 6.2 三十二工况的部分可复现

- **事实**：三十二个工况中，三十一个的数值（误差区间、覆盖区间、阈值判定）可逐项复现，但原推理引擎字节、路径与积分日志不可获得，部分记录带时间或分裂预算截断；旧"通过"结论（3 个）未获重新认证，其中一个工况因数据不足保持不可重认证。分类计数：完全重新认证 0、部分可复现 31、不可重认证 1。
- **实验开展过程**：对每个工况，先取回其模型结构、先验与数值证书的现存记录，再按工况定义用当前引擎重算误差区间、覆盖区间与阈值判定，与旧证书逐项比较。若数值一致但缺少原始引擎字节、路径日志或存在预算截断，则该工况记为"部分可复现"；若连数据本身也不足，则记为"不可重认证"。只有数值、路径与证书全部可独立重放者才允许记为"完全重新认证"，本次无一满足。
- **产出/结果**：分类计数与逐工况记录；旧"通过"数字不提升。
- **影响**：正文不得将旧工况结果作为已验证结论引用；后续实验不得以旧"通过"数量作为完成度依据。

### 6.3 撤回结论的归档

- **事实**：旧报告中"全体无界""概率测算完成""风险公式"等结论与当前可复算事实不符。
- **实验开展过程**：把旧报告的每个结论与当前可复算事实逐条对照：全体无界与修正后 104,212 行有界矛盾；概率测算完成与仅二十一点基准已验证、全量配置未执行矛盾；旧风险公式与按真实模型结构重算的结果矛盾。矛盾项逐条归档为撤回，原始材料保留。
- **产出/结果**：撤回清单与原始材料并存。
- **影响**：正文相关段落须以当前复算结果替换；后续写作以此为唯一口径。

## 七、方法的工程可行性

### 7.1 单实例判定成本可稳定估计

- **事实**：在预先声明的资源上限下，单实例判定耗时中位 0.80 秒、第 95 百分位 4.40 秒、最大 10.4 秒（修复前最大可达近 600 秒，系资源核算缺项所致，已修复并锁定回归测试）；耗时随规模平滑增长。
- **实验开展过程**：在冻结域上按八个参数轴均匀取样，对每个样本在固定资源上限下执行判定，记录墙钟时间与资源占用；按规模参数分组统计耗时的中位数、第 95 百分位与最大值。随后对耗时异常的实例逐个剖析，发现资源核算缺项（约束量未设上限）导致个别大模型耗时失控，修正后再测，耗时分布回到秒级。
- **产出/结果**：成本画像（中位 0.80 秒、P95 4.40 秒、最大 10.4 秒）；异常根因与修正记录。
- **影响**：支撑正文"工程可行"的声明；为后续全量实验的规模设定与预算声明提供依据。

### 7.2 组织方式不影响结论

- **事实**：配对同步（只比较观测与完成状态一致的运行对）与包络分组（按统计特征分组而不剪枝）不改变判定结论，只改变计算量；四种组织方式在同一批实例上结论一致。
- **实验开展过程**：四种组织方式的机制如下，对同一批模型逐一执行并比较结论：
  1. **完全枚举**：把每个运行对作为独立序列完整保存，逐对比较可观测量；
  2. **保留全部历史**：在状态上保留到当前时刻为止的完整变迁历史，用于核查判定是否依赖历史；
  3. **配对同步**：只比较"观测与完成状态一致"的运行对——即先把两条运行的可见词与完成状态对齐，再比较其是否可区分，从而省去不可能构成反例的配对；
  4. **包络分组**：按统计特征把运行对分组（包络），组内只保留统计量而不保存全部序列，用于在保持结论的前提下压缩存储；分组只是统计手段，组间不互相剪枝。
  四种方式各自输出三值判定与证据，逐实例比较；凡不一致即判为组织方式影响结论。同时记录各方式的计算量，以说明差异只体现在成本上。
- **产出/结果**：36 个重建模型 × 4 种方式共 144 次判定结论完全一致；计算量差异显著。
- **影响**：正文可声明这些变体为纯效率手段；后续性能比较不得把这些变体当作不同方法排名。

## 2. L/H 及概率层时间参数的定理约束

### 2.1 L 与 H 的定义域（唯一硬约束）

TeX 第二章 `def:bounded-complete-runs`（label 在 L708，正文 L709；`eq:bounded-complete-runs` 在 L721）原文：

> 给定 \(L\in\mathbb Z_{\geq0}\) 与 \(H>0\)，其有界子集定义为 …
> \(\mathcal R^c_{L,H}(N,\mathfrak T)=\{\rho\in\mathcal R_c^{(1)}:|\lambda(\rho)|\leq L,\ \tau(\rho)\leq H\}\)

由此得到两条硬约束：

| 参数 | 合法域（TeX 明文） | 端点/结构 | 出处 |
|---|---|---|---|
| `L` | **整数且 L≥0**，`L∈Z_{≥0}` | 可等于 0；无上界 | L708—L721 |
| `H` | **实数且 H>0**，严格正 | 无上界；`τ(ρ)≤H` 为含端点约束 | L708—L721 |

### 2.2 结论性的派生性质（非 TeX 明文，但由定义直接推出）

1. **L、H 无耦合约束**：TeX 未要求 `H≥L`、`H≤L` 或任何比例关系。第三章算例 `L=2,H=12`（L1488），贯穿示例 `L=1,H=5`（L1006、L2464），第六章微型模型 `L∈{2,3,5}`、`H∈{8,10,15,20}`（L2576），生成协议 `L=6` 配 `H∈{16.5,18.0,19.5}`、`L=10` 配 `H∈{33.0,36.0,39.0}`（L2577—2578），均显示两轴独立取值。
2. **L 只影响结构/路径长度筛选与候选枚举代价**：`B_L=Σ_{k=0}^{L}|Σ|^k`（L1443），L 增大会指数增加候选前缀数；H 只影响时间界与完成时间集合 `T^{N,T}_{L,H}(σ)⊆[0,H]`（`def:completion-time-set` L754、式 L767）。
3. **空窗口（真空）情形**：若 `H` 小于该模型首次完成时间的最小值，或 `L` 小于可完成运行的可观测词长度，则 `R^c_{L,H}=∅`，从而 `K_{L,H}=∅`，按 `thm:logical-verifier-correctness`（L1425）与 `eq:logical-verdict`（L1410）会得到 `v_L=1`。这是**数学上合法的真空真值**，但在 E3-08 中不属于“可诊断性证据”；必须单列 `VACUOUS_WINDOW`，不得计入 PASS 或诊断率分母（分母仍保留、单独报告）。
4. **L/H 与概率层时间参数不可混用**：TeX L2263 明确“并不要求第三章的 \(L,H\) 与第四章的 \(H_\psi,B_c,B_d,H_A\) 逐项相等，因为这些参数承担不同职责；真正需要一致的是最终被拿来比较的首次完成运行域”。因此 E3-08 的 L/H 敏感性不改变概率层参数，也不得把 H 当作 H_A 使用。

`def:risk-bounded-diagnosability`（label L943，正文 L944）：

## 4. 推荐三档（L/H 3×3）

### 4.1 主推荐：全部数值均在 TeX 出现的绝对三档

```
L ∈ {2, 6, 10}
H ∈ {19.5, 33, 39}
9 个 spec：(L,H) = 2/6/10 × 19.5/33/39
```

**逐值 TeX 出处与理由**

| 取值 | TeX 出处 | 选择理由 |
|---|---|---|
| `L=2` | 微型模型 `L∈{2,3,5}`（L2576）；第三章算例 `L=2`（L1488） | 小观测词窗口代表；与 L=6/10 形成低/中/高三档 |
| `L=6` | 协议生成 `j=1` 固定 `L=6`（L2577；附录 L3005—L3031） | 冻结协议中 `j=1` 的正式档 |
| `L=10` | 协议生成 `j=2` 固定 `L=10`（L2578；附录 L3032—L3042）；第六章 L 扫描端点 L=10（L2645） | 冻结协议中 `j=2` 的正式档，也是 TeX 已实际运行过的最大 L |
| `H=19.5` | `j=1` 协议 H 上端（`w=1.5`，L2577；附录如 `RMT_j1_m2_u0.1_w1.5`） | `j=1` 协议窗口上端点 |
| `H=33` | `j=2` 协议 H 下端（`w=0.5`，L2578；附录 `RMT_j2_m2_u0.1_w0.5`） | `j=2` 协议窗口下端点 |
| `H=39` | `j=2` 协议 H 上端（`w=1.5`，L2578；附录 `RMT_j2_m2_u0.1_w1.5`） | `j=2` 协议窗口上端点 |

**合法性**：`L∈{2,6,10}⊂Z_{≥0}`，`H∈{19.5,33,39}⊂(0,+∞)`，全部满足 L708—L721 的硬约束，无“事后挑容易档”问题（每个值都在 TeX 冻结文本中出现，不是按结果挑选）。

**必须同时写入 E3-08 报告的限制（关键）**：`j=1` 的协议完成窗口约在 `[?,19.5]`，`j=2` 在 `[?,39]`，两尺度不同；单一绝对 H 三档必然产生跨尺度端点：
- `H=19.5` 对 `j=2` 模型可能低于其完成时间 → `R^c_{2,19.5}` 为空 → 真空 `v_L=1`；
- `L=2` 或 `L=6` 对 `j=2` 模型可能截掉全部可完成运行 → 同样可能真空；
- `H=33/39` 对 `j=1` 模型属“扩大窗口”（合法，非真空，但与协议窗口不同）。
因此必须实现并在账本中记录 `VACUOUS_WINDOW` 判定：预注册时用模型真实结构/时间区间计算或枚举 `R^c_{L,H}` 是否非空；空的单元格只进入“窗口真空”统计，**不得计 PASS、不得并入诊断率分母**（分母保留）。

### 4.2 备选推荐：保持协议窗口的按 `j` 分档（若签署要求所有格非真空）

若主理论签署要求 9 个单元格都落在各自协议的合理窗口、避免跨尺度真空，则采用按 `j` 的 3×3：

```
j=1: L ∈ {4, 6, 8},  H ∈ {16.5, 18.0, 19.5}
j=2: L ∈ {8, 10, 12}, H ∈ {33.0, 36.0, 39.0}
```

- H 三档全部为 TeX 冻结协议值（L2577—2578；附录 L3005—L3042）。
- L 的 `6`、`10` 为 TeX 协议值；`4/8` 与 `8/12` 为围绕协议值 ±2 的合法邻档（`L∈Z_{≥0}` 允许，但 TeX 未逐字列出，须在签署中明确为“合法邻档”而非“TeX 依据值”）。
- 每个模型仍是 3×3=9 个 spec（spec_id 需含 `j` 类，因为 L 档位随 j 不同）；14,580 = 1,620×9 的总量不变。
- 优点：所有格非真空、全部贴着协议窗口；缺点：L 档位按 j 分裂，统一 `spec_id` 不如主推荐简洁。

### 4.3 推荐结论

- 若 E3-08 要求**统一 9 个 spec 定义、便于全量预注册**：采用 **主推荐** `L∈{2,6,10}`、`H∈{19.5,33,39}`，并强制 `VACUOUS_WINDOW` 单列。
- 若签署更看重**每格都有真实诊断信息**：采用 **备选** 按 `j` 分档（H 全 TeX 值，L 为协议值±2 邻档）。
- 无论采用哪一个，**都必须由主理论签署为正式 L/H 域后**才能把 `SPEC_BLOCKED` 改为具体 spec；未签署前预注册保持 `SPEC_BLOCKED`（现行脚本第 1—6、39、47 行）。
